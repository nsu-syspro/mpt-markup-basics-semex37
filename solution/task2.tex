\textbf{{\Large 1    Sequence limit}}

\textit{Task:} find the limit of the following sequence:
$$x_{n} = \frac{n^{3}-3n^{2}-5n+4}{-3n^{3}+7n^{2}+9n-20}$$
\begin{adjustwidth}{5em}{0cm}
\textit{Solution.} This is a common sequence with type $\frac{\infty}{\infty}$ To find the limit of a given sequence, one needs to divide both the numerator and the denominator by the largest degree of $n$. In this example it is $n^{3}$.
$$\displaystyle \lim_{n \to \infty}(x_{n}) = \lim_{n \to \infty}(\frac{n^{3}-3n^{2}-5n+4}{-3n^{3}+7n^{2}+9n-20}) = \dots$$
$$\displaystyle = \lim_{n \to \infty}(\frac{1-\frac{3}{n} - \frac{5}{n^{2}} + \frac{4}{n^{3}}}{-3+\frac{7}{n} + \frac{9}{n^{2}} - \frac{20}{n^{2}}}).$$
The next step is applying limit to both the numerator and the denominator and to each term.
$$ \frac{\lim_{n \to \infty}(1)-\lim_{n \to \infty}(\frac{3}{n}) - \lim_{n \to \infty}(\frac{5}{n^{2}}) + \lim_{n \to \infty}(\frac{4}{n^{3}})}{{\lim_{n \to \infty}(-3)+\lim_{n \to \infty}(\frac{7}{n}) + \lim_{n \to \infty}(\frac{9}{n^{2}}) - \lim_{n \to \infty}(\frac{20}{n^{2}})}} = \dots$$
$$ = \frac{1 - 0 - 0 + 0}{-3 + 0 + 0 - 0} = -\frac{1}{3}.$$
\textit{Answer.} $\displaystyle \lim_{n \to \infty}(x_{n}) = -\frac{1}{3}$
\end{adjustwidth}
